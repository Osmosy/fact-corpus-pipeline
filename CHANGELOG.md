# Изменения

## 2.1.0 — завершение раунда 4

- **Панели в каноне.** `build_facts.py` пишет `panel`; `config.json → panel_aliases`
  (`РФ`/`🇷🇺`, `РБ`/`🇧🇾`), панелью считается только заголовок с известным синонимом —
  иначе в «панель» попадали подзаголовки слайдов. `fact_id` не меняется.
- **`fcp` вне клона.** Понятная ошибка со списком путей и кодом 2, пример `FCP_SCRIPTS`,
  шаг в CI.
- **Исправлен `apply_dispositions.py`**: инварианты искались только по файлу предиката
  версии 1, поэтому требования под версию 4 молча пропускались. Теперь берётся последний
  инвариант любого из двух файлов. Итог не изменился (30 = 25 + 5 новых), пропуск прекратился.



## 1.1.0 — раунд 3 (проверяемый навык)

- **Входной контроль.** `validate_input.py`: значение на своей странице, подпись дословно,
  совпадение подписи и значения в двух панелях, страницы-повторы, многоточия, рваные таблицы,
  текст до первого якоря. Выход `INPUT-CHECK.json/.md`, `build_facts.py --strict`.
- **Предикат «факт в выводах» по основам слов.** `matching.py` на `snowballstemmer` (первая
  зависимость), новый чекер версии 4 в проекте, перевыпуск инвариантов и доказательств.
- **Каналы через реестр.** `backends.json` (`openai|anthropic|zcode`), ключи только из
  окружения, нормализованный `usage` и `seconds` в каждом прогоне, `cost_report.py`.
- **Шум повторов.** `--shuffle/--seed`, `stability.py`: Жаккар повторов, доли «всеми/частью/
  ни одним», невыбранные по децилям позиции и перестановочный тест.
- **Разбор «выбрал один».** `verdicts.py` (общий механизм), `single_pick.py` с меткой
  устойчивости и снимком id.
- **Аудит границы темы.** `theme_audit.py`: пакет нетематических невзятых фактов, «тема/не
  тема», предложение основ — в конфиг ничего автоматически.
- **Единый отчёт.** `report.py` → `REPORT.json/.md` с ключами вида `facts.total`;
  `ci/numbers.py` сверяет разметку `<!-- n:key -->…<!-- /n -->` со снимком.
- **Упаковка.** `pyproject.toml`, команда `fcp <шаг>`, этот файл, `SKILL.md` 2.0.0.

  отчётом без коммитов.
