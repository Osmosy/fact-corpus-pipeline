# Демо-корпус

Синтетика, написанная для этого репозитория (MIT, автор — Osmosy): две колоды по 6–7
страниц, панели РФ/РБ на чётных слайдах, повтор слайда, обрезанная ячейка. Данных закрытых
колод здесь нет и быть не должно.

Зачем: числа кейса снаружи не воспроизводятся, а конвейер должен проверяться целиком и
офлайн. Ответы моделей и вердикты лежат в `docs/facts/runs/` и `BLIND-SPOTS-REVIEW.json`,
поэтому прогон не тратит ни токена и даёт детерминированный результат.

Ожидаемые числа — `docs/demo-expected.report.json`, шаги и пояснения — `docs/demo.md`;
CI сверяет их через `ci/demo.py`.
