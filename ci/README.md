# CI

GitHub Actions включены: `.github/workflows/ci.yml` гоняет `selfcheck.py` на каждый пуш в
`main` и на пул-реквесты, матрица Python 3.11–3.13. Источник правды — бейдж в README.

`selfcheck.py` — единственная проверка, которая нужна репозиторию: скрипты компилируются,
`run_all.sh` синтаксически цел, README не ссылается на несуществующие файлы, у `SKILL.md`
валидный frontmatter и канонический раздел `## Common Pitfalls`, в файлах нет секретов.

```bash
python3 ci/selfcheck.py    # код 0 — чисто, 1 — список находок
```

## Локально, до пуша

```bash
git config core.hooksPath ci/hooks     # один раз на клон
```

Дальше каждый `git push` сначала прогоняет самопроверку; при находках пуш останавливается
(`git push --no-verify` — осознанный обход). Actions всё равно проверит заново — хук нужен,
чтобы не гонять по сети заведомо красный коммит и не ждать отчёт.

## Наблюдатель (запасной путь)

`watch.sh` проверяет `origin/main` и пишет результат в `ci/last-run.json`, коммитя его только
при смене состояния. Нужен, если Actions недоступны: кончились минуты, workflow отключён,
репозиторий отвязан от организации. В обычной работе не требуется.

```bash
ci/watch.sh
```

## История

Workflow не отправлялся, пока у токена не было scope `workflow`: GitHub отклонял пуш файла
из `.github/workflows/`. Пока scope не появился, проверка шла хуком и наблюдателем; после
выдачи scope файл лёг на место, первый прогон прошёл зелёным на всех трёх версиях Python,
и `last-run.json` из репозитория убран — он дублировал бейдж.
